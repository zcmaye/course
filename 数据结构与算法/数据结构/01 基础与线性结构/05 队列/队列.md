# 队列

队列（Queue）一种特殊的线性表，其只允许在固定的一端进行插入，在另一端删除元素操作(访问受限的线性表)。进行数据插入的一端，称为队尾，另一端称为队头。具有**先进先出**（FIFO, First In First Out）的特性。它在任务调度、消息队列、缓冲区等场景有广泛应用。

你可以把它想象成一个**单向管道**或现实生活中**排队**的场景：

- **先到的人**先接受服务，并且先离开队伍。
- **后到的人**只能站在队伍末尾，等待前面所有人完成后才能被服务。

## 重要概念

### 核心特性

队列只有**两个端点**，且功能固定：

1. **队尾（back）**：唯一允许插入的一端。
2. **队头（front）**：唯一允许删除的一端。

规则：

- 只能在**队头或队尾**操作
- 不能从中间增删元素

### 两个经典操作

1. **入队（Push）**：队列的插入操作，将元素放入队尾

   + 将一个新元素添加到队列的**末尾**。

   + 如果队列已满（针对有大小限制的队列），则无法执行此操作。

2. **出队（Pop）**：队列的删除操作，将队头元素移除

   + 将队列**开头**（队首）的元素移除，并通常返回该元素的值。

   + 如果队列为空，则无法执行此操作。

   其他辅助操作通常还包括：

   - **查看队首**：只查看队列最前面的元素是什么，而不移除它。
   - **判空**：检查队列里有没有元素。
   - **获取大小**：得到队列中元素的数量。

## 队列的实现方式

下面我将详细讲解C语言中实现队列的两种主要方式：**顺序队列**（基于数组-最常用）和**链式队列**（基于链表）。

### 顺序队列（数组实现）

- 使用一块连续的内存来存储数据。
- 需要维护两个“指针”或“索引”，一个指向队首，一个指向队尾。
- 缺点：当队首元素出队后，前面的内存位置会被空出来。如果不处理，队列会整体向数组末尾移动。常用技术是**循环队列**来解决空间浪费问题

```c
#include "SeqQueue.h"
#include <stdio.h>
#include <stdlib.h>
#include <assert.h>

SeqQueue* seq_queue_create()
{
	SeqQueue* queue = (SeqQueue*)malloc(sizeof(SeqQueue));
    if (!queue) {
        return NULL;
    }
    queue->capacity = 1;
    queue->size = 0;
    queue->front = 0;
    queue->rear = 0;

	queue->data = (ElemType*)malloc(sizeof(ElemType) * queue->capacity);
    if (!queue->data) {
        free(queue);
        return NULL;
    }

    return queue;
}

void seq_queue_destroy(SeqQueue* pthis)
{
    if (!pthis) {
        return;
    }
    free(pthis->data);
    free(pthis);
}

void seq_queue_clear(SeqQueue* pthis)
{
    pthis->size = 0;
    pthis->front = 0;
    pthis->rear = 0;
}

bool seq_queue_empty(SeqQueue* pthis)
{
    return pthis->size == 0;
}

int seq_queue_size(SeqQueue* pthis)
{
    return pthis->size;
}

int seq_queue_capacity(SeqQueue* pthis)
{
    return pthis->capacity;
}

static bool seq_queue_expand(SeqQueue* pthis)
{
    ElemType* tmp = malloc(sizeof(ElemType) * pthis->capacity * 2);
    if (!tmp) {
        return false;
    }
    //遍历循环队列，并按顺序将元素依次放入新数组中
    int tfront = pthis->front;
	for (int i = 0; i < pthis->size; i++) {
        tmp[i] = pthis->data[tfront];
		tfront = (tfront + 1) % pthis->capacity;
    }

    //释放旧数组
    free(pthis->data);

    //更新指针
    pthis->data = tmp;
	pthis->capacity *= 2;
    pthis->front = 0;
    pthis->rear = pthis->size;
    return true;
}

void seq_queue_push(SeqQueue* pthis, ElemType value)
{
    if (pthis->size == pthis->capacity && !seq_queue_expand(pthis)) {
		printf("queue is full\n");
        exit(-1);
    }

	pthis->data[pthis->rear] = value;
	pthis->rear = (pthis->rear + 1) % pthis->capacity;

    pthis->size++;
}

ElemType seq_queue_front(SeqQueue* pthis)
{
    return pthis->data[pthis->front];
}

ElemType seq_queue_back(SeqQueue* pthis)
{
    return pthis->data[pthis->rear];
}

void seq_queue_pop(SeqQueue* pthis)
{
    //pthis->data[pthis->front] = -1; //测试
    pthis->front = (pthis->front + 1) % pthis->capacity;
    pthis->size--;
}

void seq_queue_print(SeqQueue* pthis)
{
    int tfront = pthis->front;
	for (int i = 0; i < pthis->size; i++) {
		printf("%d ", pthis->data[tfront]);
		tfront = (tfront + 1) % pthis->capacity;
    }
    printf("\n");
}

SeqQueue* seq_queue_copy(SeqQueue* pthis)
{
	assert(pthis != NULL);

    SeqQueue* newQueue = seq_queue_create();
    int tfront = pthis->front;
	for (int i = 0; i < pthis->size; i++) {
		seq_queue_push(newQueue, pthis->data[tfront]);
		tfront = (tfront + 1) % pthis->capacity;
    }
    
    return newQueue;
}
```

### 链式队列（链表实现）

- 使用不连续的内存节点，每个节点包含数据和指向下一个节点的指针。
- 队首是链表头，队尾是链表尾。
- 优点：理论上可以无限扩展（受限于内存），且入队和出队操作非常简单直接。

#### LinkQueue.h

```c
#pragma once

#include <stdbool.h>

typedef int ElemType;

typedef struct QueueNode {
	ElemType data;
	struct QueueNode* next;
}QueueNode;

typedef struct LinkQueue
{
	struct QueueNode* head;
	struct QueueNode* tail;
	int size;
} LinkQueue;

LinkQueue* link_queue_create();

void link_queue_destroy(LinkQueue* pthis);

void link_queue_clear(LinkQueue* pthis);

bool link_queue_empty(LinkQueue* pthis);

void link_queue_push(LinkQueue* pthis, ElemType value);

ElemType link_queue_front(LinkQueue* pthis);
ElemType link_queue_back(LinkQueue* pthis);

void link_queue_pop(LinkQueue* pthis);
```

#### LinkQueue.c

```c
#include "LinkQueue.h"
#include <stdio.h>
#include <stdlib.h>
#include <assert.h>

static QueueNode* link_queue_create_node(ElemType value)
{
    QueueNode* node = (QueueNode*)calloc(1, sizeof(QueueNode));
    if (!node) {
        return NULL;
    }
    node->data = value;
    return node;
}

LinkQueue* link_queue_create()
{
    LinkQueue* pthis = (LinkQueue*)calloc(1,sizeof(LinkQueue));
    if (!pthis) {
        return NULL;
    }
    pthis->head = pthis->tail = link_queue_create_node(0);
    if (pthis->head == NULL) {
        free(pthis);
        return NULL;
    }
    return pthis;
}

void link_queue_destroy(LinkQueue* pthis)
{
    if (!pthis) {
        return;
    }

    link_queue_clear(pthis);
    free(pthis);
}

void link_queue_clear(LinkQueue* pthis)
{
    if (!pthis) {
        return;
    }

	QueueNode* curNode = pthis->head;
    while (curNode)
    {
        QueueNode* delNode = curNode;
        curNode = curNode->next;
        free(delNode);
    }
    pthis->head = NULL;
    pthis->tail = NULL;
    pthis->size = 0;
}

bool link_queue_empty(LinkQueue* pthis)
{
    return pthis->size == 0;
}

int link_queue_size(LinkQueue* pthis)
{
    return pthis->size;
}


void link_queue_push(LinkQueue* pthis, ElemType value)
{
	assert(pthis != NULL);

	QueueNode* newNode = link_queue_create_node(value);
    pthis->tail->next = newNode;
    pthis->tail = newNode;
    pthis->size++;
}

ElemType link_queue_front(LinkQueue* pthis)
{
    assert(!link_queue_empty(pthis));
    return pthis->head->next->data;
}

ElemType link_queue_back(LinkQueue* pthis)
{
    assert(!link_queue_empty(pthis));
    return pthis->tail->data;
}

void link_queue_pop(LinkQueue* pthis)
{
    assert(!link_queue_empty(pthis));
	QueueNode* delNode = pthis->head->next;
	pthis->head->next = delNode->next;
	free(delNode);
	//删除的是尾节点
	if (pthis->head->next == NULL) {
		pthis->tail = pthis->head;
	}
	pthis->size--;
}

void link_queue_print(LinkQueue* pthis)
{
    assert(pthis != NULL);

    QueueNode* curNode = pthis->head->next;
    while (curNode)
    {
        printf("%d ", curNode->data);
        curNode = curNode->next;
    }
    printf("\n");
}

LinkQueue* link_queue_copy(LinkQueue* pthis)
{
    assert(pthis != NULL);

    LinkQueue* newQueue = link_queue_create();
    QueueNode* curNode = pthis->head->next;
    while (curNode) {
        link_queue_push(newQueue, curNode->data);
        curNode = curNode->next;
    }
    return newQueue;
}
```

## 队列的运用

队列结构在计算机科学和软件工程中有许多应用。以下是一些常见的应用场景：

+ **任务调度**：操作系统中的进程调度，多个进程等待CPU时间片，使用队列安排执行顺序。

+ **消息队列**：在大型软件系统中，不同服务之间通过消息队列异步通信，解耦生产者和消费者（如 RabbitMQ、Kafka）。
+ **广度优先搜索**：在图和树结构中，探索所有节点时使用队列来记录待访问的节点。
+ **缓冲区**：在网络通信中，当数据包到达速度比处理速度快时，用队列缓存数据包，防止数据丢失。

这些只是一些队列结构的应用示例，队列在计算机科学中有着广泛的应用。

### 约瑟夫环问题

约瑟夫环问题（Josephus Problem）是一个经典的数学问题，描述了以下情境：有n个人围成一圈，从第一个人开始报数，报到某个数字m的人将被淘汰出局，然后从下一个人重新开始报数，直到最后只剩下一个人。求**最后幸存者的编号**

> 示例：`n=5, m=2`
>
> 人员：`0,1,2,3,4`
>
> 出局顺序：`1 → 3 → 0 → 4`，最终幸存者：`2`

#### 方法一：数组模拟

##### 思路

1. 用数组标记每个人**是否存活**，`true`= 在场，`false`= 已出局；
2. 循环遍历数组模拟环形报数；
3. 累计报数，数到 `m` 时标记该人出局；
4. 直到只剩最后 1 个存活者，输出编号

##### 优缺点

- 优点：逻辑直白，完全模拟现场过程，新手易理解；
- 缺点：效率低，`n` 很大时耗时严重，仅适合小规模数据。

##### 代码

```c
int josephus(int n, int m) {
	
	bool* arr = (bool*)malloc(sizeof(bool) * n);
	if (!arr) {
		return -1;
	}
	memset(arr, true, sizeof(bool) * n);

	int remain = n;		/*!剩余存活人数*/
	int idx = 0;		/*!当前下标*/
	int num = 0;		/*!当前报数*/

	//循环直到仅剩下一人
	while (remain > 1) {
		//如果存活，参与报数
		if (arr[idx]) {
			num++;			/*先自增，因为从1开始报数*/
			/** 如果报数等于m,则此人出局 */
			if (num == m) {
				arr[idx] = false;
				printf("%d ", idx);		/*打印出局人编号*/
				remain--;
				num = 0;	/*重置报数*/
			}
		}
		/*!计算下一个下标*/
		idx = (idx + 1) % n;		
	}

	//找到最后存活的人
	for (int i = 0; i < n; i++) {
		if (arr[i]) {
			free(arr);
			return i;
		}
	}
	free(arr);
	return -1;
}

int josephus_pro(int n, int m) {
	
	bool* arr = (bool*)malloc(sizeof(bool) * n);
	if (!arr) {
		return -1;
	}
	memset(arr, true, sizeof(bool) * n);

	int remain = n;		/*!剩余存活人数*/
	int idx = 0;		/*!当前下标*/
	int num = 0;		/*!当前报数*/

	//循环直到仅剩下一人
	while (true) {
		//如果存活，参与报数
		if (arr[idx]) {
			num++;			/*先自增，因为从1开始报数*/
			/** 如果报数等于m,则此人出局 */
			if (num == m) {
				remain--;
				num = 0;	/*重置报数*/
				//如果剩余人数为0，则返回当前下标
				if (remain == 0) {
					free(arr);
					return idx;
				}
				//如果剩余人数不为0，则将当前下标标记为出局
				else {
					arr[idx] = false;
					printf("%d ", idx);		/*打印出局人编号*/
				}
			}
		}
		/*!计算下一个下标*/
		idx = (idx + 1) % n;		
	}

	free(arr);
	return -1;
}
```

#### 方法二：递归

##### 思路

**核心数学推导（重点）**

设：

- `f(n, m)`：**n 个人、数 m 出局**，最终幸存者编号（0 起始）

**推导过程**

1. 第一轮报数，**第一个出局的人下标**：

   $k = (m - 1) \bmod n$

2. 去掉 `k` 后，剩下 `n-1` 个人，新环从 `k+1` 开始报数。

3. 对新环重新编号（映射关系）：

   | 原编号 | 新编号 |
   | :----: | :----: |
   |  k+1   |   0    |
   |  k+2   |   1    |
   |  ...   |  ...   |
   |   k    |  n-2   |

   + 设 `f(n-1, m)` 是 **n-1 人时的幸存者新编号**，还原回原编号公式：

     $f(n, m) = \big(f(n-1, m) + m\big) \bmod n$

   + **递归边界**：只有 1 个人时，幸存者就是自己

     $f(1, m) = 0$

**标准公式**

$$\begin{cases} f(1) = 0 \\ f(n) = \big(f(n-1)+m\big) \bmod n \quad (n>1) \end{cases}$$

#####  优缺点

- 优点：代码极简，数学逻辑优雅；
- 缺点：`n` 极大时会出现**栈溢出**（递归深度 = n），不适合超大数据。

##### 代码

```c
int josephus_recur(int n, int m)
{
    // 递归出口：只剩1人，编号为0
    if (n == 1)
        return 0;

	// 递推公式
	return (josephus_recur(n - 1, m) + m) % n;
}
void test_josephus_recur(int n, int m) {
	printf("=====约瑟夫环——递归=====\n");
	int res = josephus_recur(n, m);
	printf("res = %d\n", res);
}
```



#### 方法三：递推(遍历)

##### 思路

基于上面的数学公式，**把递归改成循环迭代**，从底向上计算：

- 初始：`res = f(1) = 0`

- 依次计算 $f(2),f(3),\dots,f(n)$

- 迭代公式：

  $res = (res + m) \bmod i \quad (i从2 \to n)$

##### 优缺点

优点：**时间复杂度 O (n)，空间 O (1)**，效率最高，无栈溢出问题，工程首选；

缺点：需要理解数学推导，不能直观模拟现场过程。

##### 代码

```c
int josephus_iter(int n, int m)
{
    int res = 0;  // f(1) = 0
    // 从 2 个人一直推到 n 个人
    for (int i = 2; i <= n; i++)
    {
        res = (res + m) % i;
    }
    return res;
}
void test_josephus_iter(int n, int m) {
	printf("=====约瑟夫环——递推=====\n");
	int res = josephus_recur(n, m);
	printf("res = %d\n", res);
}
```



#### 方法四：队列

##### 思路

超级简单，就 4 句话：

1. 把所有人**依次入队**
2. 循环报数：
   - **没数到 m**：队头出队，**立刻再入队尾**
   - **数到 m**：队头出队，**淘汰（不再入队）**
3. 重复直到队列 **只剩 1 个人**
4. 最后剩下的就是**幸存者**

一句话总结：

**不淘汰就 “转圈”，淘汰就 “扔掉”。**

##### 优缺点

**优点：逻辑直观、代码简单、可输出每轮淘汰者、无栈溢出；**

**缺点：时间复杂度高、空间开销大、效率低于递推法。**

##### 代码

```c
int josephus_queue(int n, int m) {
    SeqQueue* que = seq_queue_create();

    // 1. 所有人入队 1~n
    //for (int i = 1; i <= n; i++) {	//[1,n]
    for (int i = 0; i < n; i++) {		//[0,n)
		seq_queue_push(que, i);
    }

    int count = 0;
	int num;

    // 2. 只剩一个人停止
	while (seq_queue_size(que) > 1) {
		num = seq_queue_front(que);
		seq_queue_pop(que);

        count++;

        if (count == m) {
            // 数到 m：淘汰，不再入队
            count = 0;
        } else {
            // 没数到 m：回到队尾，继续转圈
			seq_queue_push(que, num);
        }
    }

    // 取出最后幸存者
	num = seq_queue_front(que);
	seq_queue_pop(que);

	seq_queue_destroy(que);
    return num;
}

void test_josephus_queue(int n, int m) {
	printf("=====约瑟夫环——队列=====\n");
	int res = josephus_queue(n, m);
	printf("res = %d\n", res);
}
```
